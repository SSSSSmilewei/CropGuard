第一套 · 计分

20 个实体样本 · 180 秒

用桌面 GUI（评分面板在这里）
  1. 先关掉「实时监测」标签页（相机只能被一个程序用）
  2. 点下面的按钮 → 桌面会弹出 GUI 窗口（约 5–10 秒）
  3. 点「打开摄像头」→ 画面出来后点「开始运行」
  4. 先空拍一张热身 → 点「↻ 新一轮评测」清空
  5. 逐个放样本 → 点「📷 拍照识别」→ 换下一只（计时自动开始）
  6. 满 20 张自动停表 → 评委判 ✓/✗ →「导出评分报告」

第二套 · 自动

定点监控 · 自动喷洒

外置摄像头（模拟片区 A 定点作业）
  1. 把 3 只以上同种害虫放进机位视野（或让它们占满画面）
  2. 点「开始定点监控」→ 画面就在本页下方出现（不用切标签）
  3. 等 1–2 秒：风险条变「高风险」→ 自动喷 + 语音播报
  4. 指一下下方「联动记录」，新增一条就说明闭环成功
  5. 演完马上点「关闭监控」（释放相机，否则下一套打不开）

出问题了怎么办（点开看 6 条）
  1. 实时画面不出来：等 10 秒（无相机要探测）→ 关标签重开 → 还不行就切手机实时模式。
  2. 点了喷但没反应：看第二套卡片的状态灯；多半是节点 IP 变了 → 不要现场改配置，改用手机"确认喷洒"继续演。
  3. GUI 打不开相机：实时监测标签没关 / 微信占用相机 → 关掉再点。
  4. 手机打不开页面：确认手机和电脑同一个 WiFi；地址用上面二维码下面那行；HTTPS 提示不受信任 → 继续访问。
  5. 数据看板空白：点导航里的「数据看板（备用）」或直接开 /dashboard-offline。
  6. 页面白屏/按钮全灰：打开 /classic 用旧版首页继续，或重启「启动演示系统.bat」。
提示：这个页面只是"遥控器"，真正在干活的是后台那个黑窗口（服务器）。别关它； 演示结束再用「停止演示系统.bat」统一关。
