# 真实昆虫标本采购单（20 只主选 + 6 只备用）

> 用途：国赛现场「幕② 20 样本限时推理」——评委对着实物逐个判 ✓/✗，**每错 1 只丢 1 分**（准确度满分 20）。
> 所以本单只挑**模型每类 mAP50 ≥ 0.82 且无已知错标/混淆**的类目，并刻意安排"同一类别、不同形态"的个体（既考泛化，又天然互为换货备份）。
> 机器可读版：`docs/specimens_plan.csv`（本文件与它逐行一致，`tests/test_specimen_plan.py` 守着）。

> 4. 自带针插标本盒、防震泡沫；**不要树脂包埋**；
> 5. 如果某个种配不到，请**先问我**再换（下面有"绝对不能拿来替代"的清单）；

## 4. 虫态 / 质量 / 包装（写进合同的硬要求）

1. **虫态不能错**：第 4–6、13–14 位**必须是幼虫**；第 7–12、15–20 位**必须是成虫**。
2. **幼虫不要针插**：针插幼虫会干瘪变形 → 用**活体**（装在透气小盒）或**酒精浸制小瓶**；不要树脂包埋。
3. **蛾类翅要完整**，按表里"展翅 / 合翅"各配一半（覆盖两种姿态，现场更稳）。
4. **完整性**：触角、足、翅无残缺，无霉斑、无异味；体表无大面积破损。
5. **标签**：每只盒底小标签（中文名 + 学名 + 采集地），**标签不得压住虫体**。
6. **包装**：自带针插标本盒 + 防震泡沫，运输不晃动；小虫（跳甲）用微针 + 小纸卡固定。

## 5. 到货验收（我们这边做，商家可用来对照）

**第一步：按编号拍照**。每只放在浅灰哑光底上，用**现场那台相机**、固定距离、斜 30–45° 拍一张，文件名就是编号：`01.jpg` … `20.jpg`（备用 `21.jpg`…），放在 `specimens/` 下。

**第二步：一条命令筛**

```powershell
# conf 0.4 = GUI 现场阈值；pass-conf 0.7 = 我们要求的安全余量
py -3.14 scripts/screen_specimens.py --dir specimens --plan docs/specimens_plan.csv --conf 0.4 --pass-conf 0.7
```

**第三步：看判定**

| 判定 | 含义 | 处理 |
| --- | --- | --- |
| `OK` | 类别对 且 置信度 ≥0.7 | 进最终 20 张 |
| `LOW` | 类别对，但 <0.7 | 先换光线/角度/距离重拍；仍低就换备用 |
| `WRONG` | 判成别的类 | **换货**（或改用备用同类别个体） |
| `NONE` | 0.4 阈值下无检出 | 同上（多半是太小/糊/背景太花） |
| `NOFILE` | 计划位没拍 | 补拍 |
| `UNPLANNED` | 多出来的照片 | 当作备用位记录 |

**第四步：换货话术**（直接发商家）

> "第 X 号（中文名）实物与要求不符/模型识别置信度偏低，麻烦按原清单同类别换一只；如果这个种没有，用备用第 Y 号顶。谢谢！"

**验收红线**：主选 20 只里出现任何 `WRONG` / `NONE`，就先用备用补位，**不要把有风险的样本带进现场**。

## 6. 为什么是这 20 只（依据，答辩也能用）

| 选它的理由 | 数据 |
| --- | --- |
| 只取 mAP50 ≥ 0.82 的类 | 全量复验见 `output/per_class_val_20261013_120802.md`（整体 mAP50 0.760） |
| 前 8 类 ≥0.95 | 斑衣蜡蝉 0.995 / 蝼蛄 0.995 / 叶蝉科 0.986 / 水稻卷叶螟 0.984 / 跳甲 0.972 / 蛴螬 0.963 / 葡萄天蛾 0.951 |
| 针插标本在训练分布内 | 我们置信度最高的实测图里就有针插展翅标本（斑衣蜡蝉 0.90、葡萄天蛾 0.90） |
| 20 张同口径实测全对 | `real_testset20/` 实测 Top1 20/20，平均 112 ms/张 |
| 避开"同科混淆集群" | 螟蛾（稻纵/玉米/桃蛀）、夜蛾（黑/黄切叶虫、粘虫、斜纹夜蛾）、盲蝽（3 类）、芫菁（3 类）——每群最多留 1–2 只 |
| 避开已知错标 | 蝗虫类 mAP50 仅 0.66 且实训图里"0.88 高置信"那张画的是绿色盲蝽；"光肩星天牛"标签可疑 |

**明确不买**（mAP50 0.33–0.85，买了大概率丢分）：
蝗虫、光肩星天牛、盲蝽科、花盲蝽、苜蓿盲蝽、芫菁、豆类芫菁、丽缘红姬甲、斜纹夜蛾、甜菜夜蛾、粘虫、甘蓝夜蛾、黄切叶虫、亚麻蕾虫、桃蛀螟。
