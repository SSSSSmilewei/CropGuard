# 小白演示手册（只做三件事）

> 你不需要懂代码、不需要开命令行。**只需要双击一个图标，然后在同一个页面点三个大按钮。**
> 配套：`启动演示系统.bat`（一键起服务 + 打开指挥台）、`停止演示系统.bat`、`启动评分GUI.bat`（备用）。

---

## 0. 先建立正确的"服务器"概念（30 秒）

你听到的"服务器互联"其实**不需要配置任何网络**：

```
你的笔记本  ──开一个黑窗口（服务器）──► 浏览器页面（指挥台）
     │                                     ▲
     └── 同一个 WiFi/热点 ── 手机扫码 ──────┘
                                   │
                                   └── 服务器再通过 WiFi 指挥 ESP32 喷淋节点
```

- **黑窗口 = 服务器**。它开着，网页和手机才有反应；关了，全断。
- 手机和电脑**连同一个 WiFi/热点**就行，不用输 IP、不用装 App，扫码即可。
- 喷淋节点（ESP32）也连同一个热点；它们的 IP 已经在配置里，**现场如果换了热点，需要别人帮你改一次**（这一步不是你能现场修的）。

**记住一句话**：你只碰浏览器和手机；黑窗口只负责"别关"。

## 1. 开机（2 分钟，只做一次）

| 步骤 | 你做什么 | 看到什么算成功 |
| --- | --- | --- |
| 1 | 双击桌面 **「农智云演示」**（第一次用：双击仓库里的 `创建桌面快捷方式.bat` 生成它） | 弹出一个黑窗口，滚动加载模型 |
| 2 | 等 10–25 秒 | 浏览器**自动打开**「农智云 · 演示指挥台」 |
| 3 | 看页面顶部一排状态灯；点一次「重新自检」 | 至少这几项是绿的：服务器、模型、语音；节点/大模型/决策可以黄（有降级方案） |

**如果浏览器没自动打开**：手动打开浏览器，地址栏输入 `http://127.0.0.1:8080/demo`。

**如果双击没反应**：右键 `启动演示系统.bat` →「以管理员身份运行」；还不行就看黑窗口里的红字，或找队友。

> 第一次启动 Windows 可能弹"防火墙是否允许"→ 点**允许**（否则手机连不上）。

## 2. 三套演示（同一个页面，从上到下三张卡）

### 第一套 · 20 个实体样本 / 180 秒（计分）

> 这张卡在页面**左边第一张**。

1. 如果刚才开过「定点监控」，先点它的「关闭监控（释放相机）」。
2. 点 **「打开评分 GUI」** → 桌面会弹出一个新窗口（约 5–10 秒）。
3. 在 GUI 里：
   - 点 **「打开摄像头」** → 看到画面；
   - 点 **「开始运行」**；
   - 先空拍一张（不放虫子）→ 点 **「↻ 新一轮评测」** 清空（把冷启动耗时不摊给第一只样本）；
   - 放第一只 → 点 **「📷 拍照识别」** → 看一眼识别结果 → 换下一只；
   - 计时**从第一张自动开始**，右上角显示 `样本 x/20`；
   - 满 20 张自动停表（或点「■ 结束本轮评测」）。
4. 评委判分：在下方日志表点一行回看照片 → 点 **「✔ 识别正确」/「✘ 识别错误」**（点错再点一次=撤销）。
5. 点 **「导出评分报告」** → `output/eval_report_<时间>.csv`。

**过关标准**：首页 `样本 0/20`、倒计时 `03:00` 出现；第一张后计时开始走；导出成功。

> ⚠️ 计时器走的是"墙上时间"，**递样本的人要练**：目标 5–6 秒/只，20 只约 110 秒，留 60 秒余量。

---

### 第二套 · 定点监控 → 自动喷洒（形态 C）

> 页面**中间那张卡**。这一套不用打开新标签页。

1. 确认卡里的开关 **「自动喷洒总闸」是开**（绿色）。
2. 把 **3 只以上**同种害虫放进摄像头视野（或让虫子/叶片占满画面）。
3. 点 **「开始定点监控（在本页看）」** → 页面下方出现实时画面。
4. 等 **1–2 秒**，你会看到：
   - 画面出现检测框、右侧风险条变 **高风险**；
   - 继电器"咔哒"、雾化出雾；
   - 语音播报"检测到…已给全体片区喷淋 3 秒"；
   - 下方「联动记录」新增一条。
5. **演完立刻点「关闭监控（释放相机）」**，否则第一套的 GUI 打不开相机。

**安全**：雾化片放进水杯/托盘再喷，别对着评委、电脑和电源。

**它为什么符合"形态 C"**：摄像头（感知）→ 服务器（判定）→ ESP32/继电器（执行）→ 语音（反馈），
四段都在现场发生，且**不需要人点喷**。

> 如果节点没上线：画面、风险条、语音、记录仍然会出现，只是没有物理出水——照演，口播"执行链路已切人工确认"。

---

### 第三套 · 手机 → 大模型 → 决策 → 手动喷洒

> 页面**右边那张卡**。手机操作，电脑页面会自动显示"最近一次决策"。

1. 手机连**同一个 WiFi/热点**，扫卡片上的二维码（或输入那行 `https://…:8443/m`）。
   - 首次提示"证书不受信任" → 点「高级」→「继续前往」。
2. 手机上点 **「📷 拍照模式」** → 对陌生害虫拍一张 → 看到：带框结果 + 虫种 + 置信度 + 风险 + 防治建议。
3. 下滑到问答，问 **「这个虫怎么防治？」** → 大模型给建议（并列出知识库依据）。
4. 下滑到喷洒控制，输入 **「给 A 片区喷 3 秒」** → 点 **「解析指令」**。
   - 此时**还没有喷**，只是在等你说"确认"。
5. 点 **「确认执行」** → 设备动作 + 语音 + 历史新增。
6. 看电脑上的第三张卡：**「最近一次决策」**会出现这条指令，并标出用的是 **规则解析** 还是 **EdgeJev 兜底**。

**口播一句**："大模型只给建议，喷不喷由人点确认——这就是我们的安全边界。"

> 手机「实时模式」默认**不会自动喷**（页面上的开关是关的）。别去打开它，否则会绕开"人工确认"的故事。

## 3. 收场（30 秒）

1. 关掉评分 GUI（或点指挥台上的「关闭 GUI」）。
2. 点「关闭监控（释放相机）」。
3. 双击 **「停止演示系统.bat」**（会关掉 8080/8443 上的服务，不动 Ollama）。

---

## 4. 三套不是三个玩具，是一条线（评委问"这仨啥关系"时背这句）

> **感知 → 决策 → 执行**：
> 第二套是"机器自己看、自己喷"（定点、无人）；
> 第三套是"人拿手机看、人来决定喷不喷"（手持、有人确认）；
> 第一套证明"看得准、看得快"，是前两套的地基。
> 三套共用同一个检测模型、同一个服务器、同一套喷淋节点。

---

## 5. 现场 6 个高频问题（照这个答）

| 现象 | 你马上做 |
| --- | --- |
| 页面打不开/白屏 | 看黑窗口还在不在；重新双击 `启动演示系统.bat`（它检测到已在跑会直接开页面）；还不行开 `http://127.0.0.1:8080/classic` |
| 「打开评分 GUI」没反应 | 看 `output/gui_launch.log`；或双击 `启动评分GUI.bat` |
| GUI 打不开相机 | 监控没关 / 微信或 QQ 占着相机 → 关掉再点 |
| 实时画面黑屏 | 等 10 秒（无相机要探测）→ 点「重启相机」→ 还不行用手机实时模式顶 |
| 点了喷但设备不动 | 看第二张卡状态灯；节点离线就继续用语音+记录演，**不要现场改配置** |
| 手机打不开页面 | 确认同一 WiFi；用二维码下面那行地址；HTTPS 警告点"继续前往" |

## 6. 上台前 10 项自检（指挥台里点「重新自检」会打勾）

```
① 服务器在线   ② 模型 27 类   ③ 喷淋链路已配置   ④ 节点至少 1 个在线
⑤ 语音就绪     ⑥ Ollama 就绪  ⑦ 看板快照已生成   ⑧ EdgeJev 模型（可选）
⑨ 手机地址可用 ⑩ 相机能打开（演第二套前试一次）
```

红叉不等于坏了：④⑧ 没有也能演，按上面的降级话术走。

## 7. 哪些地方"不太常规"（提前知道，别被问住）

1. **20 样本通常是裁判计时/判分的环节**，不一定允许你自己操作。若裁判主持：你只负责递样本和点「拍照识别」，**不要**同时开实时监控。
2. **在室内真喷水/雾**一般不鼓励：用雾化片+水杯做"可见的物理动作"，或者只让继电器咔哒；别喷到设备。
3. **"≥3 只"不是代码里唯一的判据**：实际规则是"数量 ≥6，或覆盖面积 >10%，或 ≥3 只且平均置信度 ≥0.7"。
   演示时放 **3–5 只大体型**（蝼蛄/蛴螬）最稳；被问就答"数量、置信度、覆盖面积三者综合判级"。
4. **手机实时模式原本会自动喷**（和"人工确认"矛盾）——本版已默认关闭，只保留"手动确认喷"。
5. **EdgeJev 不是"防治建议生成器"**：它只做"这句话要喷/要停/喷哪个片区"的**选择题**；
   防治建议来自本地大模型 + 知识库。两个东西别讲混。
6. **EdgeJev 模型可能没装**（335MB，在队友机器上）：指挥台状态灯会显示"决策 none"。
   没装就按第三套第 6 步的"规则解析"讲，别硬说模型在工作。
7. **不要在一个环节里同时开 GUI 和网页实时监控**：摄像头只有一个，谁先开谁占。
