## 现场准备建议（拍照 / 买标本时优先挑这些）

1. **先看每类 mAP50**（`output/per_class_val_*.md`）：**≥0.95 的 8 类**最稳；0.82–0.95 可用；**<0.80 的别拿来当计分样本**（评委按实物判对错，模型弱=白送分）。
2. **体型大、纹理独特** → 最容易拍清楚：蝼蛄、斑衣蜡蝉、葡萄天蛾、蛴螬、水稻卷叶螟、黑切叶虫。
3. **同科易混**（同一场最多留 1–2 只）：叶蝉科 ↔ 绿蝉；盲蝽科 ↔ 花盲蝽 ↔ 苜蓿盲蝽；芫菁 ↔ 豆类芫菁 ↔ 丽缘红姬甲；夜蛾科一家；**螟蛾一家（稻纵卷叶螟/玉米螟/桃蛀螟）**。
4. **两个已知坑，别选**：蝗虫类 mAP50 仅 **0.66**（且实测图里"0.88 高置信"那张画的是绿色盲蝽，标签就是错的）；`Potosiabre_vitarsis` 中文名"光肩星天牛"但图像更像**花金龟**，标签可疑。
5. **地下害虫**（金针虫/蛴螬/蝼蛄）实物是**幼虫**：要幼虫、不要成虫；幼虫用活体或浸制，**别针插**（会干瘪变形）。
6. **要下单做 20 只标本** → 直接照 **`docs/真实昆虫采购单.md`**（20 只清单 + 黑名单 + 到货验收脚本都齐了）。
