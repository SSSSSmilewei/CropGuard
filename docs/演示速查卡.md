# 株得CropGuard 演示速查卡（贴桌上）

## 只记四件事

```
启动    双击桌面「株得演示」（= 启动演示系统.bat）
页面    自动打开 http://127.0.0.1:8080/demo
黑窗口  那是服务器，别关
停止    双击「停止演示系统.bat」
```

## 三个大按钮 = 三套演示

| 顺序 | 按钮 | 你做什么 | 看到什么 |
| --- | --- | --- | --- |
| ① 计分 | **打开评分 GUI** | GUI 里：打开摄像头 → 开始运行 → 空拍一张清空 → 逐只「📷 拍照识别」 | 计时 03:00、样本 x/20、总分 |
| ② 自动 | **开始定点监控** | 放 ≥3 只虫 → 等 1–2 秒 | 框 + 高风险 + 自动喷 + 语音 + 记录 |
| ③ 手机 | 扫码 | 拍照 → 问大模型 → 说「给A区喷3秒」→ 解析 → 确认 | 结果/建议/确认卡/设备动作 |

**切换顺序**：① 和 ② 都要用相机 → 先关监控，再开 GUI；演完 ② 立刻「关闭监控」。

## 三个开关（都在页面上）

- **自动喷洒总闸**：关掉=只播语音不喷（出问题先关它）
- **手机实时自动喷**：保持**关**（第三套要人工确认）
- **立即停止喷洒**：任何异常先点它

## 十项自检（点「重新自检」）

```
服务器 / 模型27类 / 喷淋链路 / 节点≥1 / 语音 / Ollama / 看板快照 / EdgeJev(已部署) / 手机地址 / 相机
```

## 关键数字（被问就报）

- 27 类 · 验证集 mAP@0.5 **0.760** · 8 类 ≥0.95 · 20 张实拍 **20/20**
- CPU 单张 **79–250 ms**（PPT 口径 **112 ms**）· 20 张推理 **1.8–2.2 s** · 限时 180 s
- 高风险喷 **3 s** · 中风险 A 区 **2 s** · 单次上限 **5 s**
- 判级：数量 ≥6 / 面积 >10% / ≥3 只且平均置信度 ≥0.7
- EdgeJev：本机 **148–260 ms/句**，规则优先，停止兜底阈值 **0.90**

## 翻车 10 秒处置

| 现象 | 动作 |
| --- | --- |
| 页面白屏 | 重开 `启动演示系统.bat`（已在跑会直接开页面）；或开 `/classic` |
| GUI 没弹出 | `启动评分GUI.bat`；看 `output/gui_launch.log` |
| GUI 没相机 | 关监控标签 / 关微信 QQ |
| 画面黑屏 | 等 10 秒 →「重启相机」→ 手机实时顶上 |
| 喷了设备不动 | 看节点状态灯；继续用语音+记录演，别改配置 |
| 手机打不开 | 同一 WiFi；用二维码下那行地址；证书警告「继续前往」 |
