# 演示速查卡（上台前贴桌上）

```
起服务    $env:CG_DEVICE='cpu'; py -3.14 api_server.py
自检      py -3.14 tool/port_check.py
认相机    py -3.14 tool/camera_probe.py      → 看 output/camera_probe/cam_?.jpg
20样本    py -3.14 main.py                   → 右侧「现场评测」面板
手机端    https://<横幅IP>:8443/m            （HTTP 打开会自动升级；?http=1 留 HTTP）
```

## 一屏地址（PC）

| 用途 | 地址 | 备注 |
| --- | --- | --- |
| 检测台（批量/上传） | `http://127.0.0.1:8080/` | Vue |
| 实时监测（自动联动） | `http://127.0.0.1:8080/stream` | 唯一的"自动喷"入口之一 |
| 问答（RAG） | `/ask` | 本地 Ollama |
| 喷淋（节点/手动） | `/spray` | 带节点探活 |
| 设备/手机二维码/相机 | `/system` | 扫码入口在这 |
| 数据看板 | `/dashboard` | 需 `output/dashboard/snapshot.json` |
| 离线看板 | `/dashboard-offline` | 单文件，断网/双击可用 |
| 现场测评 | `/eval` | 20 样本 / 180s 计时 |
| EdgeJev | `/edge` | 模型没拷时如实显示不可用 |
| 旧版首页兜底 | `/classic` | 前端/dist 出问题时用 |

## 六幕顺序（12 分钟标准版）

```
0 看板 KPI 40s → 1 GUI 20 样本 3.5min → 2 /stream 自动闭环 2.5min
→ 3 手机 /m 拍照+问答+确认喷洒 2min → 4 /edge 规则 vs 模型 1.5min
→ 5 /dashboard 收尾 1.5min
```

- 幕 1 前：**关掉 `/stream` 标签**（相机独占）
- 幕 2 后：**关掉 `/stream` 标签**（释放相机）
- 手机"实时模式"也会自动喷（与定点同口径），不想喷就别切

## 十项自检（30 秒）

```
端口清 ? 相机认 ? 节点IP改+重启 ? 横幅5行齐 ? 手机扫码进得去 ?
/stream 出画面 ? 试喷一次响 ? /dashboard 有数 ? /eval 能开 ? /edge 如实 ?
```

## 关键数字（被问就报）

- 27 类；验证集 mAP@0.5 **0.760**；8 类 ≥0.95；20 张实拍 **20/20**
- CPU 单张 **79–250 ms**；20 张推理 **1.8–2.2 s**；限时 180 s
- 高风险喷 **3 s**、中风险 A 区 **2 s**；单次上限 **5 s**（后端+固件双钳）
- RAG：库内召回 20/20、库外拒答 10/10、越权拦截 4/4
- 单测 **234 passed / 1 skipped**

## 翻车 10 秒处置

| 现象 | 动作 |
| --- | --- |
| `/stream` 无画面 | 等 10s → 关标签重开 → `/api/camera/restart` → 手机实时顶上 |
| 节点不动 | 看 `/api/mist/status` 的 reachable；不改配置，切语音+历史 |
| 端口占用 | `py -3.14 tool/port_check.py --kill` → 重启 |
| 手机打不开 | 用横幅地址；HTTPS 没起来就用 `?http=1` 拍照模式 |
| 看板空白 | 切 `/dashboard-offline` |
| 前端白屏 | 切 `/classic` |
