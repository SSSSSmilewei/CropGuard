## 1. 开机与自检（2 分钟）

### 1.1 傻瓜方式（现场只用这个）

1. 双击桌面 **「株得演示」**（第一次用：双击仓库里的 `创建桌面快捷方式.bat` 生成）。
2. 等 10–25 秒：弹出一个黑窗口（服务器，**别关**），浏览器自动打开 `/demo`。
3. 指挥台点 **「重新自检」**，看十项灯。

**浏览器没自动打开**：手动开 `http://127.0.0.1:8080/demo`。
**双击没反应**：右键 `启动演示系统.bat` →「以管理员身份运行」；首次防火墙弹窗点**允许**（否则手机连不上）。

### 1.2 十项自检

```
① 服务器在线   ② 模型 27 类   ③ 喷淋链路已配置   ④ 节点至少 1 个在线
⑤ 语音就绪     ⑥ Ollama 就绪  ⑦ 看板快照已生成   ⑧ EdgeJev 模型（本机已部署）
⑨ 手机地址可用 ⑩ 相机能打开（演第二套前试一次）
```

红叉不等于坏了：④⑧ 没有也能演，按第 5 节降级话术走。

### 1.3 命令行方式（排错/开发用）

```powershell
py -3.14 tool/port_check.py                 # 端口 + Ollama 自检
py -3.14 tool/camera_probe.py               # 认相机（看 output/camera_probe/cam_?.jpg）
$env:CG_DEVICE='cpu'; py -3.14 api_server.py
py -3.14 scripts/build_snapshot.py --samples pictures20   # 看板快照（约 1 分钟）
py -3.14 tests/run_tests.py                               # 244 passed
```

启动横幅必须看到：`Spray transport/http_targets`、`雾化节点(mist)=[…]`、`[CERT] ✅ SAN…`、
`手机会话页(唯一入口): https://<IP>:8443/m`、`语音: engine=… ready=True`。

### 1.4 服务器互联是什么（30 秒理解）

```
笔记本（黑窗口=服务器） ── 浏览器 /demo
      │
      └── 同一 WiFi/热点 ── 手机扫码 /m ── 服务器 ── WiFi ── ESP32 节点（喷淋）
```

不需要配网络：手机和电脑同一 WiFi、扫页面二维码即可。唯一要改的是 **ESP32 节点 IP**
（串口打印的 `WIFI_OK IP=…`，填 `config/configs.yaml` 的 `SPRAY.http_targets`，改完重启服务）——
这一步不是现场小白能修的，提前让队友改好。

## 2. 技术口径（对着 PPT/项目书讲）

### 2.1 一条主线

> **个体化识别 → 毫秒感知 → 风险分级 → 查表出指令 → 人判执行 → 片区变量施药**

| PPT 里的说法 | 现场怎么对上 |
| --- | --- |
| 个体化识别 | 单张图逐虫出框、虫种、置信度（不是整片田一个结论） |
| 毫秒感知 | 单图 **112 ms**；传统测报按「天」计 |
| 27 类 / 20-20 | 27 类田间常见害虫；20 张真实样本 **20/20** 判中 |
| 精准减药 | 先分级，再按 `risk_map` 查表决定喷不喷、喷几秒——**剂量来自表，不来自模型即兴** |
| 决策不自由发挥 | 大模型只写建议；执行过片区白名单、5 秒上限、人工确认；危险表述规则侧直接拒绝 |
| 片区变量施药 | 中风险只喷 A 区 2 秒（片区隔离）；高风险才全体 3 秒应急处置 |
| 成本 | 百元级执行节点 + 现成笔记本；全本地，无云端订阅 |

**被问"为什么不用大模型直接决策"**：决策错得起，执行错不起——识别错了重拍一张即可，
喷头一按，药害/农残/误伤天敌收不回来。

### 2.2 四层架构（评委看到的）

```
摄像头/手机 → FastAPI(8080 HTTP + 8443 HTTPS) → YOLOv8 27类（best.pt, CPU 100–250ms/张）
                     │                            └─ 风险评估（数量/置信度/覆盖面积）
                     ├─ 前端 web/dist（Vue3，离线打包）
                     ├─ 手机端 /m（http→https 合一、canvas 叠框、雾化卡片）
                     ├─ EdgeJev 本地类型化决策（规则优先 + 高置信兜底，只理解不下发）
                     └─ 执行层 HTTP → ESP32（mist: GET /start?time=N；json: POST /spray）
```

### 2.3 三套演示的关系（评委问"这仨啥关系"背这句）

> 第一套证明"看得清、判得准"（27 类/20-20/百毫秒级）——地基；
> 第二套是"定点值守自动联动"：摄像头常驻，高风险按查表自动喷（无人场景）；
> 第三套是"手持人机协同"：拍照 → 大模型建议 → 规则/本地小模型解析 → **人点确认才喷**。
> 三套共用同一个模型、同一个服务器、同一套喷淋节点，区别只在"谁来按最后那一下"。

**如果评委拿 PPT 的"执行必须人来判"来问第二套**：
> "定点值守是产品里的自动模式（夜间/无人），仍过风险分级、`risk_map` 查表、5 秒上限三道闸；
> 手持模式默认必须人确认。指挥台有自动喷洒总闸，两种模式都能现场切。"

## 3. 三套演示（照做版）

### 第一套 · 20 个实体样本 / 180 秒（计分）

> 指挥台左边第一张卡。**必须用桌面 GUI**（GUI 分在这里）。

1. 若开过「定点监控」，先点「关闭监控（释放相机）」。
2. 点 **「打开评分 GUI」** → 桌面弹出 GUI（5–10 秒）。
3. GUI 里：**「打开摄像头」** → **「开始运行」** → 空拍一张 → **「↻ 新一轮评测」** 清空。
4. 放第一只 → **「📷 拍照识别」** → 看结果 → 换下一只（**计时从第一张自动开始**）。
5. 满 20 张自动停表；评委在日志表点行回看 → **「✔ 识别正确 / ✘ 识别错误」**（再点=撤销）。
6. **「导出评分报告」** → `output/eval_report_<时间>.csv`。

**评分口径（已确认）**：准确度满分 **20**（每对 1 分）+ 时效满分 **10**（180 s 内，超时每秒扣 0.5）= **30 分**。
**节奏**：5–6 秒/只，20 只约 110 秒，留 60 秒余量。
**别用**蝗虫（mAP50 0.66、图错标）、光肩星天牛（标签可疑）凑数。

### 第二套 · 定点监控 → 自动喷洒（形态 C）

> 指挥台中间卡；画面在本页下方，不用切标签。

1. 确认「自动喷洒总闸」是开。
2. 把 **3 只以上**同种害虫放进视野（或让虫/叶片占满画面）。
3. 点 **「开始定点监控（在本页看）」**。
4. 等 1–2 秒：检测框 + 风险条变**高风险** → 继电器咔哒/雾化出雾 + 语音 + 联动记录。
5. **演完立刻「关闭监控（释放相机）」**，否则第一套 GUI 打不开相机。

**真实判级规则**（被问就答）：数量 ≥6，或覆盖面积 >10%，或 ≥3 只且平均置信度 ≥0.7 → 高风险；
演示放 **3–5 只大体型**（蝼蛄/蛴螬）最稳。
**安全**：雾化片放水杯/托盘，别对着评委、电脑和电源。

### 第三套 · 手机 → 大模型 → 决策 → 手动喷洒

> 指挥台右边卡；手机操作，电脑显示"最近一次决策"。

1. 手机连同一 WiFi，扫码（或输入 `https://<IP>:8443/m`）；首次证书警告 →「高级 → 继续前往」。
2. 「📷 拍照模式」→ 对陌生害虫拍一张 → 带框结果 + 虫种 + 置信度 + 风险 + 防治建议。
3. 问 **「这个虫怎么防治？」** → 本地大模型给建议 + 知识库依据。
4. 输入 **「给 A 片区喷 3 秒」** → **「解析指令」**（此时还没喷）。
5. **「确认执行」** → 设备动作 + 语音 + 历史；电脑卡片显示 **规则解析** 或 **EdgeJev 兜底**。
6. 可选：说 **「把水停了」**（规则漏判，EdgeJev 兜底为 stop）；说 **「一直喷不要停」**（应被安全闸拒绝）。

**口播**："大模型只给建议，喷不喷由人点确认——这就是安全边界。"

### 幕间切换硬约束

- ①、② 都要相机：**先关监控，再开 GUI**；演完 ② 立刻关监控。
- 手机「实时模式」默认**不会自动喷**（第三套要人工确认），别去打开开关。
- 摄像头只有一个：GUI 和网页实时监控不能同时占。

## 5. 评委问答 / 翻车处置 / 零硬件兜底

### 5.1 高频 8 问

1. **为什么喷 3 秒？谁定的？** → `risk_map` 查表；单次上限 5 秒，后端+固件双钳（雾化片怕连续通电）。
2. **CPU 没显卡，180 秒来得及吗？** → 单张 112 ms（79–250），20 张推理 <10 s；瓶颈是递样。
3. **大模型会不会乱喷？** → 只出文本；喷淋必须过白名单+钳制+人工确认；危险词规则侧直接拒绝。
4. **断网还能用吗？** → 全本地：权重、Ollama、局域网节点；`/dashboard-offline` 单文件可离线看。
5. **EdgeJev 准确率？** → 零样本 typed-decision 8–10/13，所以只做兜底、规则优先；停止类改写最强（0.93+），阈值 0.90。
6. **27 类怎么选？** → 102 类按每类 ≥150 训练图筛出；8 类 mAP50≥95%；弱类不用于现场评分。
7. **误检怎么办？** → 置信度阈值 0.4 + 面积/数量风险规则 + 人工判分；小体型样本用备用大体型顶。
8. **和平台 ONNX 是一套吗？** → 同一权重导出，imgsz=640，平台只传 `best.onnx`。

### 5.2 翻车 10 秒处置

| 现象 | 马上做 | 对评委说 |
| --- | --- | --- |
| `/stream` 无画面 | 等 10 s → 关标签重开 →「重启相机」→ 手机实时顶上 | "定点机位在重连，手机端跑同一套推理。" |
| 节点不动 | 看 `/api/mist/status` 的 reachable；**不现场改配置**，切语音+历史 | "指令已下发，节点在复位，识别不受影响。" |
| 端口占用 | `py -3.14 tool/port_check.py --kill` → 重启 | "上一个实例没退干净，已清掉。" |
| 手机打不开 | 用横幅地址；HTTPS 没起来用 `?http=1` 拍照模式 | "两台设备要在同一网络。" |
| 没语音 | `/api/feedback/status` 看 `tts.engine/ready` | "语音后端在重启，界面反馈正常。" |
| GUI 打不开相机 | 监控没关 / 微信占用相机 | "相机被别的窗口占着，我切一下。" |
| `/dashboard` 空白 | 切 `/dashboard-offline` | "实时看板在读快照，先用离线版。" |
| 前端白屏 | 开 `/classic`（旧版首页） | "前端资源重载，用备用入口。" |

**保命底线**：规则里"场景化反馈"是物理动作 **或** 信息反馈二选一 → 喷淋全废也不怕，
只要语音还在响、界面还在出框出风险。

## 6. 工程与整合（为什么是现在这个样子）

### 6.1 三个来源

| 来源 | 贡献 | 落点 |
| --- | --- | --- |
| 主线最新 | 手机端 http/https 合一、离线看板、mist 雾化、相机看门狗、语音多后端、RAG 防幻觉 | `serve/mobile.py`、`serve/pages/dashboard.html`、`feedback/spray.py`、`tool/camera_source.py` |
| 学弟 PR#1 | Vue3 单页前端、喷淋同步等应答、实时流原始帧、上下文隔离 | `web/`、`serve/spa.py` |
| 队友 PR#3 | EdgeJev 决策、`/edge`、`/eval`、评分口径统一 | `edgejev/`、`app/edge_engine.py` |

### 6.2 关键取舍

- **PC 页面取 Vue**；**手机端 `/m` 保留主线原生页**（http→https 自动升级、canvas 叠框、断线重连、雾化卡片）。
- **`/dashboard` = Vue 实时；`/dashboard-offline` = 主线单文件快照**（断网/双击可用）。
- **喷淋以主线 mist-aware `spray.py` 为底**，只移植 PR1 的同步应答/代理/探活——PR1 的 spray 没有 mist，整取会让雾化全废。
- **实时流**：原始帧 + `image_size`，前端叠框；两次推理之间复用最近结果（不闪"无风险"）。
- **EdgeJev**：规则优先，规则拿不准才调模型；大模型永远不驱动硬件。
- 删掉队友的 `.workbuddy/`（含本机绝对路径）。

### 6.3 合并时修掉的"必炸"点

1. `api_server.py` 漏导入 `HTMLResponse` → 服务起不来；
2. `serve/pages.py` 被 PR1 删除但 `static_pages.load()` 还在用 → 页面 500；
3. GBK 控制台横幅 `✅` 触发 `UnicodeEncodeError` → 启动崩（`port_check.py` 同病）；
4. `/m`、`/dashboard` 同时被 SPA 与显式路由注册 → 手机端被顶掉；
5. 看板快照脚本 `cv2.imread` 读不了中文文件名 → 20 张样本静默变 0；
6. 串口 stop 发 `duration=1`（"再喷 1 秒"）→ 改 `0`。

### 6.4 路由总表

| 路径 | 说明 |
| --- | --- |
| `/demo` | 演示指挥台（三套演示 + 自检 + 安全闸） |
| `/` `/stream` `/ask` `/spray` `/system` | Vue SPA：检测台/实时/问答/喷淋/设备 |
| `/dashboard` | Vue 实时看板；`/dashboard-offline` 离线单文件 |
| `/m` | 手机端唯一入口（原生页） |
| `/eval` | 测评动效页（20 样本/180s，与 GUI 同口径） |
| `/edge` | EdgeJev 决策点页（选择题式） |
| `/classic` | 旧版首页兜底（不依赖 web/dist） |

### 6.5 演示安全开关

- 自动喷洒总闸：`POST /api/demo/auto_spray` → `app.inference.AUTO_SPRAY_ENABLED`；
  关掉后 `_linkage` 只播语音、不喷（手动按钮不受影响）。
- 手机实时自动喷：`PHONE.live_auto_spray: false`（默认），`POST /api/demo/phone_auto` 可切。
- 评分 GUI：`POST /api/demo/launch_gui` / `close_gui`（日志 `output/gui_launch.log`）。

## 7. EdgeJev 本地决策（已部署）

### 7.1 状态与数字

| 项 | 值 |
| --- | --- |
| 模型目录 | `edge_models/jev-int8/`（`model.onnx` 335MB + `tokenizer.json` + `edgejev.json`，共 369MB） |
| 状态 | `GET /api/edge/status` → `available=true, mode=local, provider=CPU` |
| 延迟 | 官方示例单句 77ms；本机问答 148–260ms |
| 构建终验 | 官方路由示例 `dept=billing` **0.993** |
| 模型差异 | laya（mmBERT-base 322M，INT8）；kev/nanojev/playjev 未部署 |

> 模型**不入 git**。请把 `edge_models/jev-int8/` 整个目录备份到 U 盘；换机器直接拷贝，或重跑
> `py -3.14 scripts/build_edge_model.py`（需联网 + 1–2GB 依赖）。

### 7.2 它是什么 / 不是什么

- **是**：在预设选项集（choice/score/noul）上做选择题的语言理解层，输出各选项概率；
  唯一接进链路的是 `/api/ask_command` 的**高置信兜底**（规则优先）。
- **不是**：视觉模型、防治建议生成器、检测结果解释器；不读图、不参与风险分级、不直接驱动硬件。

### 7.3 现场怎么演

1. 开 `/edge` →「指令解析」（固定选项集，无自由输入框）。
2. 固定三句：`把泵关了吧`（stop）/ `给片区A喷3秒`（spray/g1/3s）/ `一直喷不要停`（应被拒绝）。
3. 开 `/api/edge/status`：`mode=local`、`provider=CPU`、`avg_ms`——离线硬证据。
4. 手机第三套说 `把水停了` → 电脑"最近一次决策"显示 **EdgeJev 兜底**；说 `给片区A喷3秒` → **规则解析**。

**安全闸门**：spray ≥0.62 / stop ≥0.90 / group ≥0.38；规则已解析成功时不调模型。
本机复验：`把A区的水阀开一小会儿` 的 stop=0.8686，被 0.90 挡住（0.85 会误判成停止）。

### 7.4 构建环境坑（换机重跑必看）

1. `UV_CACHE_DIR` 必须指到工作区（默认 AppData 被拒）；
2. `HF_HOME` / `HF_HUB_CACHE` 指到工作区（默认 `~/.cache` 被拒）；
3. Windows 无软链权限：`huggingface_hub._create_symlink` 抛 WinError 1314 →
   构建 venv 里 `are_symlinks_supported()` 固定 False + `except OSError` 兜底；
4. `tempfile.mkdtemp()` 目录不可写 → `.edge-build-venv/.../sitecustomize.py` 改 `makedirs`；
5. 构建进程 stdout 是 GBK → `PYTHONIOENCODING=utf-8`。
