## 3. 合并时修掉的 6 个"必炸"点（已在本仓库修好）

1. `api_server.py` 漏导入 `HTMLResponse` → 启动即 `NameError`（服务根本起不来）。
2. `serve/pages.py` 被 PR#1 删除，但 `static_pages.load()` 还在用 → 看板/首页/EdgeJev 页 500。
3. GBK 控制台下横幅 `✅` 触发 `UnicodeEncodeError` → 服务启动崩（`port_check.py` 同病）。
4. `/m`、`/dashboard` 同时出现在 SPA 路由与显式路由 → 谁生效取决于注册顺序（手机端会被 Vue 顶掉）。
5. 看板快照脚本 `cv2.imread` 读不了中文文件名 → 20 张样本静默变成 0 张。
6. 喷淋 `stop()` 对串口/MQTT 发 `duration=1`（"再喷 1 秒"）→ 改成 `0`（固件语义：停止）。

## 5. 还没解决 / 需要你决定

1. **EdgeJev 模型没到本机**：`edge_models/jev-int8/` 需要从队友机器拷 3 个文件
   （`model.onnx` / `tokenizer.json` / `edgejev.json`，约 335MB）。没有它 `/edge` 显示不可用，
   `/api/ask_command` 走规则（不影响任何现场能力）。要演"模型兜底"就必须先拷。
2. **节点 IP 还是占位符**：`config/configs.yaml` 的 `http_targets` 两项都是 `172.23.153.231`，
   现场必须按串口打印的 IP 改并重启。
3. **Vue 页面没做浏览器自动化验收**：本机 Edge headless 被环境拒绝（`SEC_E_NO_CREDENTIALS` /
   crashpad 拒权），Playwright 装不上（pypi 不通）。已做的是：dist 资源自洽检查（`scripts/check_dist.py`）、
   21 个路由 200、`/api/detect` 契约实测、`/api/ask` 实测（qwen2.5 11.8s）。**建议你本机开一次浏览器点一遍**。
4. **`pictures20/` 不入 git**：新克隆的机器没有 20 张比赛图（看板/测评会空）。演示机就是本机，无影响。
5. **风险口径**：`assess_risk` 把"拍得近"当"虫害重"（面积>10% 即高风险），20 张比赛图会全判高风险 →
   `/stream` 演示时几乎放什么都会自动喷；这是"演示友好、但答辩要能解释"的点，已在流程里写了口播。
