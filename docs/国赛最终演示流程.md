# CropGuard 农智云 · 国赛最终演示流程（整合版）

> 适用：2026 睿抗 CAIR 国赛现场答辩 / 路演。整合版 = 主线最新 + 学弟 Vue 前端（PR#1）+ 队友 EdgeJev（PR#3）。
> 本文给的是**可裁剪的流程菜单**：先定"今天演哪几幕"，再按第 2 节的先后顺序执行。
> 所有地址以启动横幅为准；本文默认 `http://<PC-IP>:8080`、手机 `https://<PC-IP>:8443/m`。

---

## 0. 三句话定调（开场前自己默念）

1. **一条主线**：摄像头/手机看到虫 → 本地 YOLO 判定风险 → 规则决策 → 设备动作 + 语音反馈，**全链路离线**。
2. **两个卖点**：① 识别准且快（27 类，CPU 单张 100–250 ms，20 张推理 < 10 s）；② 决策可控（规则优先、模型只做高置信兜底、**大模型永不直接驱动硬件**）。
3. **一个底线**：任何一环坏了都不空场——降级路径在第 6 节，物理动作没了还有语音+界面+历史。

## 2. 演示总谱（推荐 12 分钟，六幕）

> 原则：**先给结论（看板）→ 再证能力（识别）→ 再演闭环（自动+手机）→ 最后讲决策与安全**。
> 每一幕都写了"你做什么 / 评委看到什么 / 你口播什么 / 坏了怎么接"。

### 幕 0 · 开场 40 秒（不切窗口）

| 你做什么 | 评委看到 | 口播 |
| --- | --- | --- |
| 大屏停在 `/dashboard`，指 KPI 四张卡 | 验证集 mAP、20 张实拍命中、单张耗时、27 类 | "这是我们系统的体检报告：27 类、验证集 mAP@0.5 76%、20 张实拍 20/20、CPU 平均百毫秒级。下面我从识别、闭环、决策三层演示。" |

> 备选：若想先讲"痛点"，PPT 停在一页架构图再切看板。

### 幕 1 · 识别主战场：20 个实体样本（3–4 分钟，评分核心）

**用 GUI（`python main.py`），不是网页**——比赛 GUI 分在这里，且它带"现场评测面板"（计时/判分/导出）。

| 步骤 | 动作 | 预期 |
| --- | --- | --- |
| 1 | 新终端 `py -3.14 main.py`（**先确认浏览器里 `/stream` 标签已关**，相机独占） | GUI 起来，右侧面板 `03:00 / 样本 0/20 / 总分 0` |
| 2 | 「打开摄像头」→ 画面有框（热身，不计时） | 预览正常 |
| 3 | 「开始运行」→ 先空拍一张 →「↻ 新一轮评测」清空 | 冷启动延迟不占第一张样本 |
| 4 | 逐个递样本 →「📷 拍照识别」→ 报类别 → 下一个 | 计时从第一张自动开始；样本数 +1 |
| 5 | 满 20 张自动停表（或提前「■ 结束本轮评测」） | 倒计时停、总分冻结 |
| 6 | 评委判分：下方日志点一行回看照片 →「✔ 正确 / ✘ 错误」（再点=撤销） | 准确度/总分实时重算 |
| 7 | 「导出评分报告」 | `output/eval_report_<时间>.csv/.xls` |

**口播**："180 秒不是算力瓶颈，是人工递样速度——20 张推理本身不到 10 秒。评分口径：准确度 20 分 + 时效 10 分，超时每秒扣 0.5。"

> 时间紧：只演 6–8 只代表性样本，然后说"其余按同一流程"，把 20 只留给正式评分环节。
> **别用**蝗虫、光肩星天牛凑数（标签噪声，评委按实物判错就是白丢分）。

### 幕 2 · 定点自动闭环（2–3 分钟，最出彩）

| 步骤 | 动作 | 预期 |
| --- | --- | --- |
| 1 | 关 GUI（或至少不占相机）→ 浏览器开 `http://127.0.0.1:8080/stream` | 状态点变绿，实时画面 + 风险条 |
| 2 | 把"多虫/覆盖大"的样本放进机位 | 彩色框 + 右侧检测列表（虫种/置信度） |
| 3 | 等 1–2 秒 | 风险条变**高风险** → **自动喷淋**（继电器咔哒/雾化出雾）+ **语音播报** |
| 4 | 指下方"联动记录" | 新增一条：高风险 · 时间 → 喷 3s · 虫种 |
| 5 | 演完**立刻关标签页**（释放相机） | 幕 3 要用 GUI/手机 |

**口播**："相机常驻 → 推理泵 5 帧/秒 → 规则判级 → 中/高风险按 `risk_map` 查表下发（高风险全体 3 秒、中风险 A 区 2 秒），语音与喷淋异步，不阻塞识别。"

**追问备答**：秒数不是大模型生成的，是配置表查出来的；单次上限 5 秒，后端与固件各钳一次。

### 幕 3 · 手机人机协同 + 雾化（2 分钟）

| 步骤 | 动作（手机） | 预期 |
| --- | --- | --- |
| 1 | 浏览器开 `https://<IP>:8443/m`（HTTP 打开会自动升级；不想升加 `?http=1`） | 「已连接 <IP>」 |
| 2 | 「拍照模式」→ 对着样本拍 | 带框结果图 + 风险 + 检测列表 + 防治建议 |
| 3 | 滑到问答，问"这个虫怎么防治？" | 本地 Ollama 回答 + 依据（RAG 召回） |
| 4 | 「给 A 片区喷 3 秒」→「解析指令」 | intent/group/duration + `needs_confirm=true`，**此时还没喷** |
| 5 | 点确认 | 节点动作 + 语音 + 历史新增 |
| 6 | （可选）「雾化控制」→ 定时 3 秒 | 雾化出雾；状态卡显示剩余秒数 |

**口播**："农户路径：拍照 → 服务器识别 → 建议 → 农户确认才下发。大模型只出文本，**永远不能直接驱动硬件**——这里有三道闸：片区白名单、时长钳制、人工确认。"

> ⚠️ 手机"实时模式"里中/高风险**也会自动联动喷淋**（与定点同口径）。不想在手机演示时喷，就别切实时模式，或先把 `SPRAY.enabled` 临时关掉。

### 幕 4 · 本地决策 EdgeJev（1–2 分钟，讲"为什么可控"）

**前提**：`edge_models/jev-int8/`（3 个文件）已从队友机器拷到位。没拷到就跳到"备选"。

| 步骤 | 动作 | 预期 |
| --- | --- | --- |
| 1 | 开 `/edge` →「指令解析」 | 固定选项集（选择题式），无自由输入框 |
| 2 | 依次试 3 句：`把泵关了吧` / `给片区A喷3秒` / `一直喷不要停` | 三栏对照：最终口径 / EdgeJev 直译 / 规则解析 |
| 3 | 点「状态」或开 `/api/edge/status` | `mode=local`、`provider=CPU`、`avg_ms`（离线硬证据） |

**口播**："它不是聊天模型，是在**预设选项集**上做选择题：输出各选项概率。我们**规则优先**，只在规则拿不准且置信度过闸（喷 ≥0.62、停止 ≥0.85）时才用它兜底。危险表述规则侧直接拒绝，模型无权翻案。"

**备选（模型没到位）**：不演 `/edge` 的试跑，改演 `/api/ask_command`：
- 正常句 → `parse_engine: "rule"`（证明确定性优先）；
- 刁钻改写（"把水停了"）→ 规则命中 stop；
- 危险句（"一直喷不要停"）→ `valid:false` + 拒绝理由；
- 同时打开 `/api/edge/status`，如实说"模型未拷入本机，接口如实报 available=false，规则链路不受影响"。
> **诚实是加分项**：把"引擎不可用会降级"讲成设计，而不是藏起来。

### 幕 5 · 数据看板 + 收尾（1–2 分钟）

| 动作 | 评委看到 | 口播 |
| --- | --- | --- |
| 开 `/dashboard`，滚一遍 | Loss/mAP 收敛曲线、27 类 mAP 条形（≥0.95 标★）、20 张实测缩略图、RAG 评测、单测 | "训练收敛、逐类能力、现场实测、防幻觉评测都在一页；数字来自真实产物，不是手填。" |
| 切 `/dashboard-offline`（或直接双击 HTML） | 同一份数据的单文件版 | "断网也能看——整条链路本来就是离线的。" |
| 收尾 | 架构图/成本表 | "端侧 YOLO + 规则决策 + 本地小模型，单机 CPU 可跑，节点百元级。" |

## 4. 评委最可能问的 8 个问题（30 秒答法）

1. **"为什么喷 3 秒？谁定的？"** → 配置表 `risk_map` 查表，不由模型生成；单次上限 5 秒，后端+固件双重钳制（雾化片怕连续通电）。
2. **"CPU 没显卡，180 秒来得及吗？"** → 实测单张 100–250 ms，20 张推理 <10 s；瓶颈是人工递样。
3. **"大模型会不会乱喷？"** → 不会：大模型只出文本；喷淋必须过白名单+钳制+人工确认；危险词规则侧直接拒绝。
4. **"断网还能用吗？"** → 全本地：本地权重、本地 Ollama、局域网节点；`/dashboard-offline` 单文件可离线看。
5. **"EdgeJev 准确率多少？"** → 老实说：零样本 typed-decision 只有 8–10/13，所以**只做兜底**，规则优先；停止类改写最强（0.93+），阈值 0.85 卡在真假停止的空档里。
6. **"27 类怎么选的？"** → 从 102 类按每类 ≥150 训练图筛出；8 类 mAP50≥95%；弱类（蝗虫 0.66）不用于现场评分。
7. **"误检怎么办？"** → 置信度阈值 0.4 + 面积风险规则 + 人工判分；现场用小体型样本时用备用大体型顶。
8. **"和平台提交的 ONNX 是一套吗？"** → 同一权重导出，imgsz=640；平台只传 `best.onnx`。

## 5. 翻车点与 10 秒处置

| 现象 | 马上做 | 对评委说 |
| --- | --- | --- |
| `/stream` 无画面 | 等 10 秒（无设备探测）→ 关标签重开 → `POST /api/camera/restart` → 手机实时顶上 | "定点机位在重连，手机端跑同一套推理。" |
| 节点不动/继电器没声 | 看 `/api/mist/status` 的 `reachable`；多半 IP 变了 → **不现场改配置**，切语音+历史继续 | "控制指令已下发，节点我在复位，识别端不受影响。" |
| 起服务 `[Errno 10048]` | `py -3.14 tool/port_check.py --kill` → 重启 | "上一个实例没退干净，已清掉。" |
| 手机页打不开 | 用横幅那句地址；确认同一网段；HTTPS 没起来就用 `?http=1` 拍照模式 | "两台设备要在同一网络，我确认一下。" |
| 没语音 | `/api/feedback/status` 看 `tts.engine/ready` | "语音后端在重启，界面反馈正常。" |
| GUI 打不开相机 | `/stream` 标签没关 / 微信占用 | "相机被别的窗口占着，我切一下。" |
| `/dashboard` 空白 | 快照没生成 → 切 `/dashboard-offline`（已内嵌） | "实时看板在读快照，先用离线版。" |
| `/edge` 显示不可用 | 模型没拷 → 走幕 4 备选（规则对照 + status 如实说明） | "模型未部署到本机，接口如实降级。" |
| 前端页面 404/白屏 | 切 `/classic`（旧版首页，不依赖 dist） | "前端资源在重载，用备用入口。" |
| 标本识别错 | 换备用同类别个体；别争辩 | "这只是同类不同形态，我换一只再确认。" |

**保命底线**：规则里"场景化反馈"是**物理动作 或 信息反馈**二选一 → 喷淋全废也不怕，只要语音还在响、界面还在出框出风险，这 5 分就保住。

## 8. 演示前最后一次自检（30 秒口令版）

```
端口清 ? → 相机认 ? → 节点 IP 改并重启 ? → 横幅 5 行齐 ?
手机扫码进得去 ? → /stream 出画面 ? → 试喷一次响不响 ?
/dashboard 有数 ? → /eval 能开 ? → /edge 状态如实 ?
```

十项全过再上台；任何一项不过，按第 5 节选降级路径，**不要现场修硬件**。
